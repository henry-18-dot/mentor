决策 B

视觉语言：边缘色条 / 纸面底色 / 强调色用量

Anthropic 公开的 pptx skill 里有一句很冲的话："**绝不要标题下划线、卡片单边色条、页眉页脚色带——那是 AI 生成的标志**；要区分卡片请用淡底、阴影或图标"。mentor 现在恰好有 4 处这类条纹。这一页决定它们的去留。

  • 4 处边缘色条
    命中行 4px 竖标、左栏命中片段 2px 竖线、选中模式下划线、目录项 3px 竖线
  • 暖白纸面 #fbfaf7
    Anthropic 点名避免奶油/米色系（F5F5DC/FAF0E6/FAEBD7/FFF8E1）
  • 强调色用量克制
    靛蓝只出现在引用/选中/命中，未滥用

三个方案

B1保持现状

命中用左侧竖色条 + 选中模式下划线标示。指示明确、改动为零。

取舍与代价

方案好处代价验收层面要动什么
B1零风险被点名的“AI 标志”仍在无
B2去掉 AI 味；命中指示更柔淡底在深色模式下要重新算对比度；左栏命中可辨识度略降，需要靠圆点/图标补回改 4 处 CSS + 深色模式各算一遍对比度；像素亮度基线要重取
B3最像“专业阅读器”暖白带来的“纸感”会丢；卡片层级变平后，组件之间的边界要靠间距撑，间距体系要一起调同上 + 改 --paper 与阴影令牌
我的建议：B2（先不动纸面颜色）。"边缘色条是 AI 标志"这条来自一手 skill，值得信；但"暖白纸面"是 mentor 现有的性格，而 Anthropic 那条规则是为 PPT 写的（投影环境与屏幕阅读不是一回事）。所以先做 B2 去掉条纹，纸面颜色留到你看过真实渲染再定。
